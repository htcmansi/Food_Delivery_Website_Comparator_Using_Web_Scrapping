echo "# Food Delivery Website Comparator Using Web Scrapping

This project is designed to compare food delivery websites (like Zomato, Swiggy) using web scraping techniques. It extracts data from these platforms in real time and compares the restaurants based on user-defined parameters such as location, cuisine, and rating.

## Features

- **Web Scraping**: Scrapes data from food delivery websites like Zomato and Swiggy using Python libraries such as BeautifulSoup and Requests.
- **Real-Time Data**: Retrieves live data from the web for restaurant listings, ratings, and more.
- **Location and Cuisine-based Filtering**: Users can select their location and preferred cuisine to see the top 5 restaurants matching their preferences.
- **Responsive Interface**: The project includes a Flask-based web interface to interact with users dynamically.

## Technologies Used

- **Python**: For the backend logic and web scraping.
- **BeautifulSoup**: For parsing HTML and extracting data.
- **Requests**: To make HTTP requests and retrieve web pages.
- **Flask**: For creating the web application to display results dynamically.
- **HTML, CSS, JavaScript**: For building the frontend user interface.
